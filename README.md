# birthday-adventure-game
🎂 A personalised birthday platformer game you can gift to someone you love — no coding skills needed.


🎂 Birthday Adventure — A Personalised Platformer Gift
Ever wanted to give someone a gift they've never received before? This is a single HTML file you drop into a folder, fill in a few names and messages, and hand to someone you love as a fully playable birthday game — no servers, no installs, no coding knowledge required.
🎮 What it is
A side-scrolling platformer where the player jumps across platforms, ducks through glowing crystal caves, discovers 8 personalised memory cards, and finds hidden VHS tapes — ending with a birthday cake and a candle to blow out.
🎁 Who it's for
Anyone who wants to give a birthday gift that's genuinely one-of-a-kind. Fill it in for a parent, partner, sibling, best friend, or anyone worth celebrating.
✏️ What you can personalise
Everything lives in one CONFIG block at the top of the file:

Name & age — shown on the HUD, start screen, and celebration ending
8 memory cards — each has a title, message, emoji icon, and optional photo
3 VHS tapes — record live voice messages in-browser, or supply your own audio files
Character appearance — skin tone, hair colour, shirt, shoes, eye colour, mustache, glasses, and party hat
End-screen photo — a final image that pops up after the candle is blown out

🚀 How to use it

Download index.html
Open it in a text editor and fill in the CONFIG block at the top
Drop any photos into the same folder and reference them by filename
Open in a browser — done. Share the folder, host it on GitHub Pages, or just hand them a USB stick.

No framework. No build step. No dependencies. One file.
